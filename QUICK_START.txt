⚠️  YOU NEED TO DOWNLOAD AND INSTALL THESE FIRST:

1. FLUTTER SDK
   → Download: https://docs.flutter.dev/get-started/install/windows
   → Extract to: C:\src\flutter\
   → Add to PATH: C:\src\flutter\bin

2. ANDROID STUDIO
   → Download: https://developer.android.com/studio
   → Install with default settings
   → Install Android SDK Command-line Tools

3. ADD YOUR LOGO
   → Put your logo.png file in: assets\logo.png
   → Recommended size: 180x180 pixels

═══════════════════════════════════════════════════════════════════

📋 AFTER INSTALLING FLUTTER & ANDROID STUDIO:

1. Open a NEW terminal/command prompt
2. Navigate to this folder
3. Run: flutter doctor
4. Run: flutter doctor --android-licenses (accept all)
5. Double-click: run_app.bat

═══════════════════════════════════════════════════════════════════

🚀 QUICK RUN COMMANDS:

# Install dependencies
flutter pub get

# Run on Chrome browser
flutter run -d chrome

# Run on Android (emulator or phone)
flutter run
