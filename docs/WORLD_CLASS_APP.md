## 📱 HOW IT WORKS

### Photogrammetry Workflow:
1. Tools > 3D Reconstruction
2. Capture 12 guided photos
3. View 3D model (instant preview)
4. Complete entry form (auto-saves)
5. Save to Firebase (or offline queue)

### Offline Mode:
- All data cached locally
- Queue shows pending uploads
- One-tap sync when online
- Zero data loss guarantee
