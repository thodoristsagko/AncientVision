Android Studio is now open. Follow these steps:

═══════════════════════════════════════════════════════════════════
STEP 1: Install SDK Command-line Tools
═══════════════════════════════════════════════════════════════════

1. In Android Studio, look for "More Actions" or "Customize"
   
2. Click "All settings..." OR navigate to:
   File → Settings (or press Ctrl+Alt+S)
   
3. In the left sidebar, go to:
   Appearance & Behavior → System Settings → Android SDK
   
4. Click the "SDK Tools" tab at the top
   
5. Check the box next to:
   ☑ Android SDK Command-line Tools (latest)
   
6. Click "Apply" button at the bottom right
   
7. Click "OK" to confirm installation
   
8. Wait for download to complete (~100 MB)
   
9. Click "Finish" → "OK"

═══════════════════════════════════════════════════════════════════
STEP 2: Accept Android Licenses
═══════════════════════════════════════════════════════════════════

After Step 1 is done:

1. Open a NEW terminal/command prompt

2. Run this command:
   flutter doctor --android-licenses

3. Type "y" and press Enter for each license (about 7 total)

═══════════════════════════════════════════════════════════════════
STEP 3: Create an Android Emulator
═══════════════════════════════════════════════════════════════════

Option A - Using Android Studio (Recommended):

1. In Android Studio, click:
   Tools → Device Manager

2. Click "Create Device" button

3. Select a device (e.g., "Pixel 5") → Click "Next"

4. Download a system image:
   - Recommended: "Tiramisu" (Android 13) or latest
   - Click the download icon next to it
   - Wait for download to complete
   - Click "Next"

5. Name your emulator (or keep default) → Click "Finish"

6. Click the ▶ play button to start the emulator

Option B - Using Command Line:

1. Run: flutter emulators --create

2. This will create a default emulator

═══════════════════════════════════════════════════════════════════
STEP 4: Run Your App on Android
═══════════════════════════════════════════════════════════════════

1. Make sure the emulator is running (you'll see an Android phone window)

2. In your project folder, run:
   flutter run

3. Or double-click: run_app.bat
   Then select option 2 (Run on Android)

═══════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

• "cmdline-tools component is missing"
  → Complete Step 1 above

• "Android license status unknown"
  → Complete Step 2 above

• "No devices available"
  → Make sure emulator is running (Step 3)
  → Check with: flutter devices

• Emulator is slow
  → Enable hardware acceleration in BIOS (Intel VT-x or AMD-V)
  → Or use a physical Android device instead

═══════════════════════════════════════════════════════════════════

Once all steps are complete, run: flutter doctor

You should see checkmarks for Android toolchain!
